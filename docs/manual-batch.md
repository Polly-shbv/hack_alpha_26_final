# Ручной пакетный анализ — версия 1.3

26.10.2026. Изменение по прямому указанию владельца: расписание выключено, запросы Gemma экономятся объединением новостей и компаний. Передача обезличенного контекста явно разрешена в чате 26.10.2026; отдельное повторное подтверждение не требуется.

## Пользовательский сценарий

- «Источники → Собрать и проанализировать»: загрузить доступные публикации Lenta, РИА и ТАСС, затем создать один пакет для трёх доступных компаний и выбранной роли.
- «Анализировать загруженные новости»: использовать уже сохранённые материалы, без повторного сетевого сбора.
- «Обновить анализ» в сводке при выбранной Gemma также запускает пакет всех трёх компаний. Смена компании, роли, открытие страницы, перезапуск и ожидание не вызывают модель.
- В карточке и подробном разборе есть «Оригинал новости» с прямой ссылкой на страницу издателя. Ссылка сохраняется и в экспорте. Для ТАСС явно указано, если получен только RSS-анонс.

## Предел одного пакета

Для каждой из трёх компаний локально выбираются до трёх наиболее релевантных свежих событий за семь дней. Итого до девяти пар «компания — новость» для выбранной роли. Компании и события в запросе не дублируются; отдельно передаются общие фрагменты банка и список пар. На модель выделено до 12 288 выходных токенов. Пакет не дробится на скрытые дополнительные генерации.

Поиск, расширение поиска банковского контекста и ранжирование выполняются до генерации. В одном ручном запуске допускается максимум один POST /chat/completions. Нет автоматического исправления ответа через LLM, повторов при 429/5xx, периодического повторного анализа или повторной отправки после перезапуска. GET каталога моделей и проверка ключа не являются генерациями. Кнопка «Проверить подключение» не вызывает chat/completions.

Проверенные ответы кэшируются по компании, роли, событию, версии модели и фактическим основаниям. Неизменившиеся пары используют кэш; при полностью готовом кэше запросов модели ноль. Отсутствие подходящих свежих новостей тоже не вызывает модель. Повторное нажатие во время обработки возвращает тот же пакет. История трёх компаний публикуется одной транзакцией.

## Проверка и ограничения

Для каждой пары проверяются точные факты/цитаты и ID оснований. Пропущенные или неподтверждённые части заменяются явно отмеченными локальными правилами без второго запроса. Чужие компании, роли и повторяющиеся пары отклоняются. Частичный или ошибочный ответ не выдаётся за полностью успешную аналитику Gemma. Статус пакета показывает количество компаний/новостей, реальные генерации, кэш и ошибки.

Автообновление выключено в рабочей базе и принудительно выключается при запуске. Устаревший запрос включения расписания получает MANUAL_ONLY. Фоновый поток только исполняет явно поставленные пользователем задания. Опрос готовности браузером обращается к локальному API и не расходует генерации модели.

В OpenRouter передаются только разрешённые обезличенные признаки: отрасль/ОКВЭД, флаги кредита и лизинга, страны, неизвестные параметры и фрагменты источников. Выручка, суммы платежей, списки контрагентов и свободные комментарии не передаются. Ключ остаётся в локальном .env с правами 0600 и не включается в архив.

API: POST /api/v1/analysis/batches; GET /analysis/batches/{id}; POST /analysis/batches/{id}/cancel. История обычных запусков содержит batch_id и ссылки на общий запрос. Учёт токенов/стоимости общего запроса выполняется один раз; история каждого участника не дублирует расходы.

Проверки версии — docs/audit/manual-batch-check.json. Реальная проверка модели — docs/audit/manual-batch-live-check.json. Автотесты используют только сгенерированные данные и mock-транспорты; внешний сетевой доступ в pytest заблокирован. Дополнительные учебные файлы перечислены в docs/test-data-replacement.md.
