# Ресурсы

- Временный знак «А» набран системным шрифтом и подчёркнут красной линией. Демонстрационная эмблема, не официальный SVG Альфа-Банка. Для точного бренда заменить согласованным SVG.
- Контурные lucide-react 0.468.0 — ISC, локальный bundle. Один набор иконок, декоративные SVG скрываются aria-hidden.
- Радар в frontend/src/main.tsx — собственная SVG-композиция в коде, не AI-растровый макет. Источник: создан для проекта. Текст и кнопки остаются HTML. Статичен, не пульсирует.
- Шрифт: системный -apple-system/BlinkMacSystemFont/Segoe UI/sans-serif. Внешние webfonts не загружаются.
- Референсы из PDF извлечены только для аудита в tmp/pdfs; не используются как фон интерфейса.
- Учебные PDF — собственные технические fixtures; список происхождения/замены в test-data-replacement.md. Не брендовые публикации.
