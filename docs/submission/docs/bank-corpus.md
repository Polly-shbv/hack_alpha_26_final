Первичные даты получены из распознанных заголовков; ставка, сталь и Бонд Бриф дополнительно сверены с рендерами первой страницы. Точное время в PDF не указано. Для отсечения материалов хранится консервативная верхняя граница — конец указанного дня; интерфейс показывает только дату, без выдуманного времени. У золота `published_at=null`, сохранён отчётный период `2026-08`; источник виден в библиотеке, но не участвует в датированном RAG.

В перечне приложения 2 упомянут `Commodities performance`, однако отдельного PDF с таким названием в папке нет. Вместо него среди девяти файлов присутствует обзор российской стали 2021 года. Оригинальное имя, исторический период и байты сохранены; файл не объявляется актуальным обзором сырья за 2026 год.

Для каждого PDF рядом находится `.ocr.json`: текст по страницам, способ распознавания, число символов и показатели уверенности. `manifest.json` фиксирует SHA-256 оригиналов и OCR, источник, название, дату и её точность. Импорт прекращается при несовпадении контрольных сумм. Подтверждение относится к происхождению из предоставленной папки. Полная ручная вычитка OCR, таблиц, чисел и порядка колонок не выполнена; пользователь видит предупреждение и может открыть оригинал.

OCR использует [Apple Vision](https://developer.apple.com/documentation/vision/vnrecognizetextrequest), локально, с русским и английским языками и CPU. Версии Python-обёрток зафиксированы отдельно. Данные компаний при OCR не нужны; документы во внешнюю модель не отправляются. Предусмотрен Tesseract как необязательный локальный вариант.

Повторная подготовка из исходных скачанных файлов:

```sh
.venv/bin/python scripts/prepare_bank_corpus.py --input /путь/к/PDF --output /путь/к/новому-корпусу
```

Сначала создаётся `manifest.pending.json`. После сверки происхождения, заголовков и дат формируется `manifest.json`. Не переносите `source_confirmed=true` на другие байты PDF. Загрузка в отдельную БД:

```sh
ALFA_DB=/путь/к/alfa.sqlite3 .venv/bin/python scripts/import_bank_corpus.py --folder data/reference/bank
```

При обычном старте этот корпус подхватывается автоматически, если манифест присутствует. Unit-тесты используют `ALFA_SKIP_REFERENCE_CORPUS=1` и собственные данные; отдельный браузерный контур проверяет настоящий корпус. Пакет для коллеги включает проверенные OCR-sidecars и манифест без тяжёлых оригинальных PDF. Ссылки на оригиналы сохраняются; кнопка локального скачивания показывается, только если PDF действительно включён в установку.

Эти материалы предоставлены для кейса, не являются общедоступным лицензированным датасетом. Локальная обработка и разбор не означают независимой проверки текущих рыночных оценок банка.
