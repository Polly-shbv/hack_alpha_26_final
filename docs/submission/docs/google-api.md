# Google Gemma — версия 1.4

Текущий провайдер: прямой Gemini Developer API Google, REST v1beta.
Разрешённая модель строго `gemma-4-26b-a4b-it`, alias `Gemma 4 26B A4B`.
Авторизация — заголовок `x-goog-api-key`; ключ не включается в URL, браузер,
логи, Git или передаваемые архивы. Локальная конфигурация: `.env`, образец `.env.example`.

Документация, проверенная 26.10.2026:
- [Gemma в Gemini API](https://ai.google.dev/gemma/docs/core/gemma_on_gemini_api).
- [Тарифы Google, раздел Gemma 4](https://ai.google.dev/gemini-api/docs/pricing#gemma-4): вход и выход бесплатны, платный тариф отсутствует.
- [Ключи и права доступа](https://ai.google.dev/gemini-api/docs/api-key).

Google не возвращает стоимость в usageMetadata и не публикует цены в models.get.
Поэтому 0 ₽ в учёте означает расчёт по документированному бесплатному тарифу,
а не подтверждение банковской выписки. Код допускает только точный ID Gemma и
официальный base URL с нулевыми ценами; другие модели, инструменты, grounding
и платные fallback не включены. Проверять тариф перед сменой модели/провайдера.

Упакованные выдержки: до трёх новостей на компанию, один фрагмент до 900 символов
на новость и до двух банковских фрагментов по 700 символов на событие. Исходные
полные тексты сохраняются локально и доступны для проверки. Компании, события и
банк дедуплицированы. В запросе только отрасль/ОКВЭД, кредит/лизинг, страны,
неизвестные признаки и ID оснований. Полная выручка, платежи, контрагенты,
остальные продукты и комментарии не отправляются.

Сбор и анализ запускаются только кнопкой. Один пакет — не более одной генерации;
исправление ответа и автоматические повторы отсутствуют. Ответы проверяются до
публикации по точным цитатам, ID и правам доступа. Для отклонённой пары явно
показываются локальные правила. Кэшируются только прошедшие проверку пары.
Таймаут ожидания Google — 240 секунд, соединения — 15 секунд. Дневной лимит
40 попыток, минутный 5; 429 даёт временную блокировку, не повторный запрос.

«Проверить подключение» выполняет models.get с ключом без генерации. Успешный
models.get сам по себе не доказывает корректность новостного анализа. Реальные
результаты и ограничения записаны в `audit/google-live-check.json` и QA-report.

В пользовательской конфигурации согласие на передачу контекста уже дано.
В передаваемом пакете оно по умолчанию выключено и задаётся получателем.
Архив не содержит ключ владельца проекта.
