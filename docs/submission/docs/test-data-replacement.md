## Пакет для передачи коллеге

`exports/alfa-context-demo.zip` — сгенерированный пакет для просмотра, содержит
копии перечисленных fixtures и учебных PDF, собранный интерфейс и backend.
Это не новый источник данных. Перед следующей передачей пересобрать из
актуального кода через `scripts/package-demo.py`. Реальные три профиля остаются
реальными; новости и PDF остаются учебными. Архив не содержит рабочую БД автора,
исходные CSV или ключи. У получателя создаются свои `data/local/alfa.sqlite3` и
`data/local/uploads/*`; для live их заменить отдельной БД и реальным корпусом,
как описано выше. `manifest.sha256.json` внутри архива — автоматически
сгенерированный список контрольных сумм; пересоздавать вместе с архивом.

дату и происхождение, затем пересоздать контрольные суммы в манифесте.

Скачанные `.pdf` в этой папке — исходные файлы из папки кейса, не результат

`docs/audit/*check.json` — результаты проверок; пересоздавать запуском тестов,
