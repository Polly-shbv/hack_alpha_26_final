# Демонстрационный доступ и данные

Пароль и регистрация не нужны. При открытии localhost автоматически создаётся
«Демо-пользователь», id demo, системная роль admin. Это локальная тестовая сессия,
не учётная запись интернет-банка. Роли CEO / CFO / казначейство переключают
представление и не являются отдельными паролями.

Компании:
- U_9250 — строительство.
- U_1941 — оптовая торговля.
- U_106783 — производство электрического оборудования.

Профили взяты из исходных CSV и не синтетические. Для учебного сквозного сценария
не нужны исходные CSV, ключ модели или рабочая БД автора.

В архиве исходников автоматически подхватываются:
- data/fixtures/events.json — шесть учебных новостных сценариев;
- data/fixtures/texts.json — детерминированные учебные интерпретации;
- data/fixtures/profiles.json — три обезличенных профиля;
- data/fixtures/test-documents/synthetic-bank-01.pdf … synthetic-bank-09.pdf — девять учебных PDF;
- data/fixtures/news-sites/ — синтетические HTML для тестирования парсеров;
- data/reference/bank/ — отдельный OCR-корпус реальных материалов кейса.

Происхождение и правила замены подробно перечислены в test-data-replacement.md.
