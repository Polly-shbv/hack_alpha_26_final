# Проверка основного сценария — 5–7 минут

## Обязательный воспроизводимый путь без ключа

1. Запустить исходники через `docker compose up --build` и открыть
   http://127.0.0.1:8000/select-company. При запуске готового демо использовать
   адрес, показанный его launcher. Логин и пароль не вводятся: создаётся локальный
   сеанс «Демо-пользователь», системная роль admin.
2. Выбрать U_9250 и роль CEO. На чистой установке используется учебный режим;
   при необходимости в «Настройках» выбрать «Локальные правила · учебные и внешние
   материалы» и сохранить.
3. В сводке компании нажать «Обновить анализ» и дождаться завершения.
   Ожидается сводка с маркировкой учебных материалов, фактом, условным влиянием
   и недостающими данными. Нулевой расход: LLM не вызывается. Сравнение учебной
   ставки доступно через «О проекте» (`/about`) → «Ставка»; эта ссылка открывает
   сравнение, а не запускает новый анализ.
4. Открыть карточку события. Проверить разделение факта, связи с профилем,
   условного риска, действия и оснований. Если проверенной банковской позиции нет,
   это должно быть указано явно. Синтетическая новость не имеет выдуманной внешней ссылки.
5. Сохранить разбор, открыть «Сохранённое» и выгрузить Markdown. Открыть историю
   и проверить, что выполненный анализ сохранён.
6. Переключить компанию на U_1941, затем U_106783; сравнить отрасль, признаки
   кредита/лизинга и доступные сценарии. Результаты могут различаться по профилю.
7. В «Источниках» импортировать `data/fixtures/test-documents/synthetic-bank-01.pdf`
   из распакованного архива исходников. Проверить учебную маркировку, статус
   обработки и доступность документа. Повторный идентичный импорт не должен
   создавать новую копию источника по SHA256.
8. Перезапустить контейнер: в другом терминале той же папки выполнить
   `docker compose restart`. Обновить страницу: история и сохранённый разбор остаются.
9. Открыть AI-помощник: ожидается окно «Скоро», без рабочего чата.

## Дополнительная проверка свежих внешних материалов

1. В «Источниках» нажать «Собрать и проанализировать» один раз. Нужен интернет.
   Без ключа используется локальная интерпретация.
2. Дождаться завершения, проверить издателя, дату и доступную ссылку на оригинал.
   ТАСС иногда предоставляет только RSS-анонс. Состав свежих новостей и их
   релевантность заранее не фиксированы; пустой результат допустим.
3. Для проверки LLM настроить собственный ключ Google, включить реальный режим
   и разрешить передачу обезличенного контекста. На пакет трёх компаний выполняется
   максимум один generateContent, ожидание до 240 секунд. Метка в интерфейсе —
   «AI-анализ». Отклонённые ответы заменяются явно помеченными локальными правилами.
4. Для уже загруженных материалов использовать «Анализировать загруженные новости».
   Неизменившиеся подтверждённые ответы берутся из кэша. Автообновление отключено.
