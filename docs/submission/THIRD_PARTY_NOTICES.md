# Сторонние компоненты и данные

React/React DOM (MIT), React Router (MIT), TanStack Query (MIT), Vite (MIT), TypeScript (Apache-2.0), lucide-react (ISC), FastAPI (MIT), Starlette (BSD-3-Clause), Pydantic (MIT), Uvicorn (BSD-3-Clause), httpx (BSD-3-Clause), python-multipart (Apache-2.0), BeautifulSoup (MIT), pypdf (BSD-3-Clause), PyMuPDF (AGPL-3.0; проверить лицензионную стратегию перед закрытым распространением), python-dotenv (BSD-3-Clause), pytest (MIT), Vitest (MIT), Playwright (Apache-2.0), axe-core (MPL-2.0), SQLite (public domain).

Версии: package.json/pnpm-lock.yaml, requirements.lock.txt. Исходные CSV/PDF/PPTX предоставлены владелицей для хакатона; права на публикацию не подразумеваются. Они не включаются в Docker build context. Обезличенные выбранные профили воспроизводятся в fixtures, исходник и SHA сохранены в аудите. Учебные события/тестовые PDF созданы по спецификации и не являются настоящими новостями или аналитикой банка.

Детерминированный fixture provider не является LLM. В актуальной версии подключён прямой Google API; подробности приведены в разделе выпуска 1.4 ниже. RSS/HTML-сбор реализован. Интернет-банк, SSO и банковские операции не подключены; AI-помощник — интерфейсная заглушка.


## Дополнения версии 1.1

- PyObjC: pyobjc-core/Cocoa/CoreML/Quartz 12.2.2 и Vision 11.1, MIT, необязательная локальная обёртка macOS. Версии — requirements-ocr-macos.lock.txt. Apple Vision — системный компонент macOS, используется для OCR на CPU; не внешний AI-сервис.
- gdown 5.2.0, MIT, использован только как временная утилита загрузки общедоступной папки кейса, не компонент runtime.
- Девять PDF из ссылки в приложении 2 кейса: оригиналы и OCR описаны в docs/bank-corpus.md, происхождение и SHA-256 в data/reference/bank/manifest.json. Они не заменяют учебные synthetic-bank PDF. Условия кейса и авторство исходных материалов сохраняются; лицензия на исходный код проекта не распространяется на эти PDF.


## Дополнение 1.2 — новостные источники и runtime API

Lenta.ru, РИА Новости и ТАСС — внешние издатели. Используются их публичные RSS и доступные страницы; авторство и ссылки сохраняются. Новости не объявляются собственностью проекта и не включаются в переносимый архив как предзагруженный корпус. Включённые HTML-примеры news-sites сгенерированы для тестов. Недоступные статьи ТАСС не обходятся; RSS-анонсы помечаются отдельно.

Историческая интеграция 1.2: OpenRouter — внешний API-посредник для конкретно настроенной Google Gemma 4 26B A4B IT :free. Код проекта не содержит веса модели или ключ пользователя. Нулевые тарифы проверяются перед вызовом; доступность и ограничения определяет провайдер. Внешняя передача обезличенного контекста отдельно разрешается владельцем. На этапе 1.2 генерация OpenRouter не была подтверждена из-за 429. В текущей конфигурации этот провайдер не используется; успешная Google-генерация подтверждена аудитом версии 1.4.

## Google API, выпуск 1.4 (26.10.2026)

Основной LLM-провайдер изменён с OpenRouter на Gemini Developer API Google,
прямой native REST generateContent, модель `gemma-4-26b-a4b-it`. Модель Gemma 4
из разрешённого списка кейса. Входные/выходные токены бесплатны согласно
https://ai.google.dev/gemini-api/docs/pricing#gemma-4, проверено 26.10.2026.
Лицензия и условия модели/сервиса определяются Google. Использование бесплатного
API регулируется условиями Google, включая обработку передаваемых данных.
Передача обезличенного контекста отдельно разрешена владельцем проекта.
Google SDK не добавлен: используется зафиксированный httpx. OpenRouter остаётся
регрессионно проверяемым адаптером, в текущем запуске не используется.
