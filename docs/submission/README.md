# Альфа Контекст — комплект для экспертной проверки, v1.4.1

Локальное приложение персонализированной новостной аналитики: внешнее событие →
профиль компании → возможное влияние → банковские основания → проверяемый разбор.
Для трёх обезличенных компаний доступны сводка, подробный разбор, ссылки на
источники, сравнение, карта влияния, история, сохранение и экспорт.

## Что внутри

- `alfa-context-source.zip`: точные исходники v1.4.1, тесты, документация, lock-файлы,
  миграции SQLite, учебные данные и OCR-корпус девяти материалов кейса.
- `alfa-context-demo.zip`: собранный интерфейс и backend для просмотра без Node.js.
- `alfa-context-test-data-v1.4.1.zip`: отдельный набор учебных данных и реестр происхождения.
- `configuration/`: отдельные копии Dockerfile, Compose, lock-файлов и шаблона конфигурации.
- `docs/demo-script.md`: основной сценарий и ожидаемые результаты.
- `docs/architecture.md`, `docs/data-contracts.md`, `openapi.json`: архитектура, данные и API.
- `docs/test-accounts.md`: демонстрационный доступ и три компании.
- `docs/qa-summary.md`, `evidence/`: результаты проверок и фактические аудиты.
- `THIRD_PARTY_NOTICES.md`: компоненты, модели, внешние сервисы и заглушки.
- `VERSION.txt`, `SHA256SUMS.txt`: идентификатор версии и целостность файлов.
- `submission-description.txt`: готовое описание для поля формы решения.

Это сопроводительный комплект, собранный 26.10.2026. Вложенный архив исходников
оставлен без изменений. В его документации есть исторические разделы ранних
выпусков; текущие инструкции и итог проверки приведены в настоящем комплекте.

## Воспроизводимый запуск через Docker — основной способ

Нужны работающий Docker Engine / Docker Desktop с Compose 2.24+, свободный
локальный порт 8000 и интернет для первой сборки зависимостей. Python и Node.js
на компьютере отдельно устанавливать не требуется: Python 3.12.10 и Node 22.14.0
зафиксированы в Dockerfile, pnpm 11.25.0 — в сборке и package.json.

1. Распаковать `alfa-context-source.zip` целиком.
2. Открыть терминал в полученной папке `alfa-context-source`.
3. Выполнить единую команду:

```sh
docker compose up --build
```

4. Дождаться сообщения о запуске Uvicorn и открыть:
   http://127.0.0.1:8000/select-company
5. Пройти `docs/demo-script.md` из настоящего комплекта. Пароль и API-ключ для
   учебного сквозного сценария не нужны. Учебные данные загружаются автоматически.
6. Проверка доступности API: http://127.0.0.1:8000/api/v1/health
7. Swagger: http://127.0.0.1:8000/docs ; схема: http://127.0.0.1:8000/openapi.json

Остановка: Ctrl+C, затем `docker compose down`. История сохраняется в именованном
volume. Не запускать `docker compose down -v`, если историю нужно сохранить.
При занятом порте остановить прежний экземпляр приложения на 8000.

## Быстрый просмотр без Docker

Нужен Python 3.11–3.13 (рекомендуется 3.12) и интернет для первой установки
зафиксированных зависимостей. Распаковать `alfa-context-demo.zip` и выполнить
внутри полученной папки:

```sh
python3 start_demo.py
```

Windows: `py -3.12 start_demo.py`. Также приложены «Запустить демо.command» и
«Запустить демо.bat». Адрес обычно http://127.0.0.1:8765/select-company ; если порт
занят, новый адрес отображается в терминале. Оставить терминал открытым.
Основной подтверждённый Linux-путь запуска — Docker, native Windows launcher
на Windows отдельно не проверялся.

## Конфигурация и реальный анализ

Без `.env` приложение работает с локальными правилами и учебными событиями.
В `/settings` выбрать «Локальные правила · учебные и внешние материалы».
Для реальной генерации скопировать `.env.example` из исходников в `.env` рядом с
compose.yaml, задать свой Google API-ключ, перезапустить контейнер командой
`docker compose up --build`, выбрать реальный режим и отдельно разрешить передачу
обезличенного контекста в настройках.

| Переменная | Значение / назначение |
|---|---|
| ALFA_PROVIDER | google |
| ALFA_MODEL_ID, ALFA_APPROVED_MODEL_ID | gemma-4-26b-a4b-it; точная разрешённая модель |
| ALFA_API_BASE | https://generativelanguage.googleapis.com/v1beta |
| ALFA_API_KEY | Собственный ключ получателя; в комплект не включён |
| ALFA_FREE_ONLY | 1 |
| ALFA_INPUT_RUB_PER_MILLION, ALFA_OUTPUT_RUB_PER_MILLION | 0; конфигурация проверенного бесплатного режима |
| ALFA_FREE_DAILY_REQUESTS, ALFA_FREE_MINUTE_REQUESTS | Локальные ограничения 40 и 5; квоты Google могут быть строже |
| ALFA_DB | Путь SQLite; в контейнере постоянные данные /app/data/local |
| ALFA_ORIGIN | Дополнительный локальный origin при изменении адреса |
| ALFA_AUTH_MODE | demo для локальной демонстрации; задан в Compose |

Ключ хранится только на сервере. Полный шаблон — `configuration/.env.example`.
Обновление выполняется по кнопке. Один пакет объединяет до девяти пар новость /
компания для трёх компаний и использует максимум одну генерацию. Автоматического
обновления, автоматических повторов и платного запасного провайдера нет.
Сбор свежих внешних новостей возможен с локальной интерпретацией без ключа;
реальная генерация требует собственного ключа и согласия. Подробности — docs/google-api.md.

## Архитектура и проверки

React / TypeScript / Vite → FastAPI / Pydantic → SQLite / FTS5. HTML/RSS-парсеры
Lenta, РИА и ТАСС, PDF/OCR-корпус, ранжирование, пакетный LLM-адаптер и проверка
точных цитат работают на backend. Production-интерфейс обслуживает тот же процесс
Uvicorn; отдельная внешняя БД для локального запуска не нужна.

Исходники содержат backend/tests, tests/e2e, scripts/frontend-unit.mjs и инструкции
запуска проверок в своём README. Подтверждено: 149 backend, 9 frontend unit,
21 браузерный сценарий на macOS; на Linux 20 сценариев без macOS pixel baseline,
Docker smoke и сохранение истории после restart. Подробности — docs/qa-summary.md.

## Данные и границы демонстрации

События, структурные HTML-примеры и девять synthetic-bank PDF — учебные данные.
Профили U_9250, U_1941 и U_106783 получены из предоставленных CSV; они обезличены,
но их признаки не придуманы. Девять настоящих материалов кейса включены отдельно
как OCR JSON с манифестом и ссылками на оригиналы. Оригинальные CSV/PDF, рабочая
база автора, загруженные им файлы и ключи не включены. Реестр происхождения и замены
— docs/test-data-replacement.md. Учебные PDF не являются позицией банка.

ТАСС может возвращать только RSS-анонс; это явно отмечается. OCR не полностью
вычитан. Условная гипотеза не является финансовым прогнозом. При отклонении
ответа модели показываются локальные правила с соответствующей меткой.
AI-помощник — окно «Скоро»; банковские операции и production SSO не подключены.
Адреса 127.0.0.1 открываются на компьютере эксперта после запуска, общий сервер
для удалённого просмотра в комплект не входит.
