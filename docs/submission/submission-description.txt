Альфа Контекст — локальный прототип персонализированной новостной аналитики для крупного бизнеса. Объединяет обезличенный профиль компании, свежие новости Lenta, РИА и ТАСС и корпус аналитики банка. Показывает факт, возможное влияние, основания, условные гипотезы и недостающие данные; сохраняет ссылки на оригиналы, историю, сравнение и экспорт.

Обновление выполняется по кнопке. Google API используется для одного пакетного анализа трёх компаний; автообновление и автоматические повторы выключены. Есть воспроизводимый учебный сценарий без ключа и внешней модели. Реальная генерация требует собственного API-ключа Google и согласия на передачу обезличенного контекста.

Технический комплект содержит исходники v1.4.1, готовое демо, README, Dockerfile/Compose, lock-файлы, шаблон переменных окружения, THIRD_PARTY_NOTICES, тестовые данные и описание локального доступа без пароля. Дополнительно приложены сценарий проверки, архитектурная схема, модель данных, OpenAPI, результаты тестирования и скриншоты.

Запуск исходников: распаковать alfa-context-source.zip, в папке alfa-context-source выполнить docker compose up --build, открыть http://127.0.0.1:8000/select-company. Подробности и ожидаемые результаты — README.md и docs/demo-script.md.
