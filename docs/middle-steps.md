# Пункты 2–4 кейса: реализация 1.1

25.10.2026. Основание — нумерованные блоки на странице 6 файла «Альфа Хак_Новостная аналитика.pdf». Пункт 1 и пользовательский сценарий пункта 5 сохранены. Работа выполнена в согласованном тестовом режиме; платные LLM не вызывались.

| Пункт | Что работает | Основной код |
|---|---|---|
| 2. Сбор и обработка | HTML с JSON-LD/метаданными, PDF, текст, пакетный сбор RSS/Atom; классификация по 15 темам, извлечение стран, чисел и цитат; дедупликация и группировка сообщений; локальный OCR | `backend/app/content.py`, `ingestion.py`, `feeds.py`, `stories.py`, `ocr.py` |
| 3. Персональный отбор | ОКВЭД/отрасль, кредит/лизинг, страны ФТС, роль, давность и неопределённость; объяснение каждого компонента; scorer не содержит ID трёх компаний | `backend/app/relevance.py` |
| 4. Интерпретация | Общие условные механизмы для новых публикаций, отдельные риски и возможности, действия по роли, основания в тексте и профиле; датированные выдержки из материалов банка; отказ от неподтверждённого влияния | `backend/app/interpretation.py`, `analysis.py`, `llm.py` |

Раньше `ranking-v1.json` содержал веса по конкретным ID, а интерпретация выбирала готовый текст по теме. Теперь рабочий scorer версии 2.0 сопоставляет признаки. Шесть исходных сценариев оставлены как отдельный воспроизводимый regression fixture; их тексты не применяются к импортированным событиям. Для новых событий работает общий локальный механизм. При наличии подтверждённых материалов банка он используется и для исходных сценариев.

## Сбор и происхождение

«Источники → Добавить материалы → RSS / Atom» принимает публичную ленту и собирает до пяти статей за запуск. Каждая ссылка повторно проходит защиту от SSRF; частичные ошибки сохраняются в отчёте задания. DTD/entities запрещены, размер XML ограничен, сбор ограничен по времени и числу записей. Подписка по расписанию выключена.

Пример для ручного просмотра: `https://www.cbr.ru/rss/RssPress`. Этот адрес опубликован на [странице RSS Банка России](https://cbr.ru/development/RSS/). Проверены чтение 14 записей и полный путь одной статьи: RSS → HTML → классификация `rate` → локальный анализ с нулевой стоимостью. Отчёты — `docs/audit/rss-live-check.json` и `rss-end-to-end-check.json`.

Тестовый режим определяет способ интерпретации, а не происхождение публикации. URL/RSS сохраняют внешнее происхождение и издателя; ручные примеры и тестовые PDF помечены как учебные. «Внешний источник» не означает независимой проверки всех утверждений автора. Авторство Альфа-Банка не устанавливается по словам в тексте или выбранному типу материала.

Идентичный контент разных издателей сохраняется отдельными источниками. Группируются только близкие заголовки и тексты одного дня в одной области доступа. Разные числа отмечаются как конфликт; обе версии остаются доступны. При исключении источника событие пересобирается по оставшимся доступным материалам. Будущие и недатированные источники не попадают в snapshot.

## Корпус банка и OCR

Из ссылки в приложении 2 кейса получены 9 PDF: 64 страницы, 155 653 символа OCR. Оригиналы сохранены без изменения. Полный список, даты и расхождения — `docs/bank-corpus.md`. У восьми документов установлена дата с точностью до дня; у золота известен только отчётный месяц, поэтому он исключён из датированного поиска. Обзор стали действительно относится к 2021 году и не переименован в актуальный обзор commodities.

Встроенный поиск использует FTS с префиксами, датой отсечения, типом корпуса и правами доступа. Учебные PDF не становятся банковской позицией. Цитата сохраняет ID фрагмента, страницу, дату и ссылку на оригинал; OCR помечен предупреждением. Подтверждено происхождение из папки кейса, а не безошибочность всего распознанного текста. Банковский материал используется как макроэкономический контекст, не как оценка банком конкретной компании.

На macOS дополнительный OCR устанавливается командой:

```sh
.venv/bin/python -m pip install -r requirements-ocr-macos.lock.txt
```

После загрузки скана с `needs_ocr` нажмите «Повторить обработку». Поддержан также локальный Tesseract с `rus+eng`; этот вариант здесь не запускался. Повторная обработка создаёт новую текстовую версию и сохраняет исходный PDF. Для корпусного импорта скана стратегии размером 34,9 МБ используется отдельный проверяемый локальный импорт; пользовательский лимит загрузки 20 МБ сохранён.

## Самопроверка и границы

Оркестратор выполняет семь шагов. Он передаёт в интерпретацию реальные фрагменты новости, а не только её заголовок. Неподтверждённое утверждение отклоняется и может быть исправлено один раз с повторной проверкой. При недостатке оснований выполняется дополнительный тематический поиск; новые подтверждённые фрагменты вызывают пересчёт интерпретации. При отсутствии новых оснований вывод остаётся условным. Все действия видны в истории; публикация результатов атомарная.

ФТС не доказывает импорт, товар или маршрут. Наличие банковского продукта не раскрывает остаток долга или формулу ставки. Релевантность — инженерный балл, не вероятность финансового ущерба. Сетевой бонус не начисляется за число контрагентов. Рыночная доля и эффект в рублях не выдумываются.

Риски и возможности теперь отображаются и экспортируются по `kind`. Условное снижение стоимости денег/меди может дать возможность, если применимость подтверждена; у нерелевантной компании механизм воздерживается от вывода. Смена роли меняет вопросы и действия. Дата анализа в интерфейсе текущая; явно заданный API `as_of` и старые snapshots сохраняются.

Разрешённый LLM-адаптер получает ту же схему фактов, признаков и фрагментов, с проверкой evidence и бюджета. Он проверен mock-ответами. Реальные вызовы и качество ответов моделей не проверены: нужны инструкция организаторов, exact model ID, тарифы и локальный ключ. Локальные правила не выдаются за ответы LLM. OCR, HTML/RSS и локальная интерпретация не расходуют токены.

Итоговые результаты автоматических проверок находятся в `docs/audit/middle-steps-check.json`. Старый `qa-report.md` оставлен как отчёт версии 1.0. Реестр всех учебных и производных файлов обновлён в `docs/test-data-replacement.md`.
