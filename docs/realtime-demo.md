## Реальные источники

- Lenta: https://lenta.ru/amp/ ; RSS https://lenta.ru/rss/news
- РИА: https://ria.ru/ ; RSS https://ria.ru/export/rss2/archive/index.xml
- ТАСС: https://tass.ru/ ; RSS https://tass.ru/rss/v2.xml

У Lenta и РИА проверено извлечение полного текста. ТАСС возвращает 403 для проверенных страниц статей: сохраняется только достаточно содержательный анонс официального RSS. Такой материал явно помечен `feed_excerpt`; приложение не выдаёт анонс за полный текст. Короткий или пустой анонс считается ошибкой. Блокировки не обходятся.

Деловые рубрики и тематические заголовки получают приоритет при ограничении пятью статьями на источник за один цикл. Обработанные страницы ротируются для обнаружения исправлений. Публикации старше семи дней и с неизвестной датой не попадают в автоматическую актуальную ленту. Ошибки не заменяют сохранённый полный текст кратким анонсом.

## Настройка и демонстрация

1. Запустить `./scripts/dev`; открыть http://127.0.0.1:5173/select-company.
2. В «Настройках» выбрать локальные правила или разрешённую модель. Включить автоматический сбор и сохранить настройки.
3. В «Источниках» нажать «Обновить сейчас» или дождаться проверки по расписанию. Посмотреть счётчики, даты, частичные ошибки и ограничения ТАСС.
4. Открыть компанию: готовая сводка обновится автоматически. Выбор другой роли добавит её в автоматический анализ.
5. Открыть событие и проверить факт, интерпретацию, метод анализа, условия, банковские цитаты и первоисточники.
6. Повторить сбор: неизменённые статьи сохраняют ID и версию. Исправление текста создаёт новую версию.
7. Перезапустить программу: история и очередь сохраняются в `data/local`; прерванный цикл помечается и повторяется.

Запуск не создаёт системный cron и не работает после остановки приложения. Интервал 3–5 минут означает периодический опрос, а не моментальную доставку со стороны издателя.

## Внешняя модель и передача контекста

Ключ находится только в локальном `.env` с правами 0600; он не включается в архив, браузер, исходники, отчёты или логи. API base URL — https://openrouter.ai/api/v1, ID — google/gemma-4-26b-a4b-it:free, alias — Gemma 4 26B A4B из разрешённого списка кейса. Каталог подтвердил нулевые тарифы. Проверка авторизации вернула 200; две попытки генерации вернули 429. Успешная реальная генерация не заявляется.

Автоматическая проверка разрешений отклонила сквозной тест с передачей бизнес-контекста компаний в OpenRouter. Поэтому `allow_external_context` по умолчанию false. До отдельного согласия владельца профили обрабатываются локально, включая режим live; API модели получает только отдельную безопасную проверку подключения без профиля.

При согласии в OpenRouter передаются обезличенные отрасль/ОКВЭД, флаги кредита и лизинга, страны, релевантные выдержки новости и публичной банковской аналитики. Выручка, суммы платежей, списки контрагентов и свободные комментарии профиля исключены из контекста. Согласие задаётся отдельно в настройках; разработчик его автоматически не включает.

При 429, недоступности или неподтверждённых фактах используется локальная интерпретация с явной отметкой. Это не считается ответом Gemma. Неподтверждённая стоимость останавливает бесплатные вызовы. Локальные квоты по умолчанию — 40 попыток в день и 5 в минуту; неуспешные попытки также учитываются. Лимиты провайдера могут быть строже, а локальная база не видит использования ключа другими программами.

## Контракты и основные файлы

- `publishers.py`, `feeds.py`, `ingestion.py`: извлечение и происхождение.
- `collection.py`, `bank_watch.py`, миграция 002: расписание, версии, очередь и состояния.
- `analysis.py`, `llm.py`: пересчёт, основания, кэш, квоты и разрешение внешней передачи.
- `frontend/src/collection-ui.tsx`: состояние сбора и обновление результатов.
- `/api/v1/collection`, `/collection/refresh`, `/collection/sources/{id}`, `/collection/articles`, `/sources/{id}/versions`, `/companies/{id}/watch`: основные API.
- `/collection/bank-watches`: настройка наблюдений за банковскими PDF.

Сводные результаты находятся в `docs/audit/realtime-check.json`; реальные сетевые проверки — в `news-sites-live-check.json`, `realtime-local-live-check.json`, `free-model-live-check.json`. Все синтетические файлы перечислены в `docs/test-data-replacement.md`.
