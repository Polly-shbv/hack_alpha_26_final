# Передача демо коллеге

Архив для просмотра: `exports/alfa-context-demo.zip`. Его можно отправить через
мессенджер, почту или файловое хранилище. Распаковать целиком, затем следовать
README внутри. Нужен Python 3.11–3.13 (рекомендуется 3.12) и интернет для первой установки зависимостей.
Node.js и API-ключ не нужны. macOS: «Запустить демо.command»; Windows:
«Запустить демо.bat». Есть запуск через Python для Linux и резервный вариант
для macOS/Windows. По завершении установки браузер открывается автоматически.

Архив содержит собранный интерфейс, backend, миграции, зафиксированные
зависимости, demo fixtures, учебные PDF, реестр происхождения данных и проверку
целостности `manifest.sha256.json`. Три профиля компаний основаны на реальных
предоставленных CSV. Исходные CSV, связи физических лиц, исходные задания,
секреты, `.env`, окружения, текущая база/загрузки/история автора не включены.
Это пакет для просмотра; frontend-исходники и инструменты разработки в него
не входят. Для совместной разработки нужно передать полный проект отдельно.

Программа работает только на компьютере получателя. Обычный адрес:
`http://127.0.0.1:8765/select-company`; при занятом порте выбирается следующий.
Пользователь видит адрес в окне запуска. Закрыть приложение можно через Ctrl+C.
Данные получателя сохраняются в `data/local` рядом с приложением.

Ссылка `http://127.0.0.1:5173` с компьютера автора у коллеги не откроет этот
экземпляр. Для общего доступа по одной ссылке потребуется отдельное размещение
с настройкой доступа: текущий демонстрационный вход рассчитан на localhost.
Публичное размещение и туннель при создании архива не выполняются.

Пересборка после изменений:

```sh
./scripts/build
python3 scripts/package-demo.py
```

В окружении автора с отдельным проверенным runtime можно указать
`--source /private/tmp/alfa-context-clean-check`. В этой папке должны быть
актуальные backend, dist, fixtures и документы.

Проверка передачи: архив распакован в отдельную папку; контрольные суммы и
отсутствие ключей/рабочей БД/исходных CSV проверяются автоматически. Запуск с
новым окружением и БД проверен на macOS. Windows/Linux не проверены на своих ОС.

Версия 1.2 поддерживает сбор свежих новостей. В архиве он изначально выключен; получатель включает его в настройках. Для локальных правил ключ не нужен. Свой ключ модели можно задать в локальном .env, затем отдельно разрешить передачу контекста в настройках. Ключ автора в архив не включается. Подробнее: realtime-demo.md.

Версия 1.3: запуск сбора и аналитики только по кнопке; один пакет для трёх компаний. Автообновление выключено. Прямые ссылки на оригиналы находятся в карточках. Для реальной Gemma получателю нужен собственный ключ; ключ автора не включён. См. manual-batch.md.

Версия 1.4: Google API подключён напрямую. Полные исходники с тестами и CI — `exports/alfa-context-source.zip`; история локальных коммитов — `exports/alfa-context.bundle`. Ключ и рабочая база не входят ни в один архив. Актуальные ограничения и статус сдачи: submission.md.
