## Исправление чистого Git-клона — 1.4.1

Первый GitHub Actions (40271596216) выявил, что Git не переносит пустую
папку `public`: Dockerfile ожидал её в COPY. Добавлен `public/.gitkeep`,
поэтому каталог присутствует после обычного клонирования. Локальная проверка
1.4.0 использовала рабочую папку с этим пустым каталогом и не выявила проблему.
Опубликованный тег 1.4.0 сохранён; исправление выпускается отдельным тегом 1.4.1.
Данные, анализ и интерфейс этим исправлением не изменяются.
