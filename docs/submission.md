# Комплект технической сдачи — версия 1.4.1

Требования сверены со страницей 8 кейса «Альфа Хак_Новостная аналитика».

| Пункт кейса | Что подготовлено |
|---|---|
| Исходники с историей | Локальный Git, одна ветка main; проверенные исходники 1.4 и финальные материалы сдачи зафиксированы фактической датой. Переносимая история — `exports/alfa-context.bundle`. Ранние технические чекпойнты сохранены отдельно в data/local/git-before-release из-за таймаутов File Provider |
| Однозначная версия | Тег `v1.4.1`; SHA256 исходников — `audit/version.json`. Перед публикацией проверить `git rev-parse v1.4.1` |
| README | Назначение, окружение, архитектура, запуск, конфигурация, проверки и сценарий |
| Docker | Dockerfile + Compose; `docker compose up --build`; локальный порт 8000, сохранение данных в volume |
| Фиксация окружения | Python 3.12.10 в Docker, Node 22.14.0, pnpm 11.25.0, оба lock-файла |
| Сторонние компоненты | THIRD_PARTY_NOTICES.md, Google Gemma и источники указаны |
| Тестовые данные | fixtures, synthetic-bank PDF, HTML/RSS/model doubles, реестр происхождения и замены |
| Проверки | Backend, frontend, E2E, accessibility; QA-report и JSON-аудиты |
| Дополнительные материалы | OpenAPI `/docs`, архитектура, модель данных и контракты, demo-script |
| Готовый просмотр | `exports/alfa-context-demo.zip`, без Node.js и ключа |
| Полный перенос проекта | `exports/alfa-context-source.zip`: исходники, тесты, lock-файлы, CI и OCR-корпус; без рабочей БД и секретов |

В Git/архивы не включены `.env`, ключи, исходные CSV, рабочая история/загрузки,
окружения и оригиналы PDF из личной папки. Для корпуса кейса включены OCR-копии
с исходными ссылками и проверенной provenance. Получатель добавляет собственный
ключ при необходимости; учебное демо работает без него.

## Что ещё требуется для формальной сдачи

1. **GitHub:** [Polly-shbv/hack_alpha_26_final](https://github.com/Polly-shbv/hack_alpha_26_final),основная ветка `main`, версия приложения — тег `v1.4.1`. Для сдачи передать
   жюри URL и SHA тега, соблюдая фактический дедлайн организаторов. Репозиторий
   публичный: исходники доступны по ссылке. Если владелец сделает его приватным,
   по кейсу потребуется предоставить доступ `alfa-hack-2026`.

Docker runtime проверен локально после установки Docker Desktop: сборка Linux arm64,
API, три профиля, сквозной сценарий, сохранение истории после restart. CI повторяет
проверку (`scripts/check-container.py`). Это больше не блокирует техническую сдачу.

Результаты GitHub Actions доступны в Результаты GitHub Actions доступны в [Verify local demo](https://github.com/Polly-shbv/hack_alpha_26_final/actions/workflows/verify.yml).
Linux CI явно исключает только принятую пиксельную macOS baseline;
функциональные сценарии, overflow и axe остаются. Внешний бесплатный сервер
в кейсе рекомендован дополнительно; публичное размещение не выполнялось.

Финальный контроль: 149 backend-тестов на macOS и Linux/Docker, 9 frontend unit,
21 браузерный сценарий; архив просмотра запущен после чистой распаковки.
