# Пилотная проверка содержания — 26.10.2026

Это небольшая ручная инженерная проверка свежих публикаций, а не оценка точности
модели на репрезентативной выборке клиентов. Реальные материалы не совпадают с
шестью учебными golden-сценариями. Последний пакет: 3 компании, 3 уникальные
новости, 6 пар, один HTTP 200 Google, 7520 входных и 3355 выходных токенов.
Формальная проверка приняла 4 ответа модели; 2 отклонила из-за неточных банковских
цитат и опубликовала явно отмеченные локальные правила. См. audit/google-live-check.json.

| Компания / тема | Результат содержательного просмотра |
|---|---|
| U_9250 / строительство в регионах | Участие компании не утверждается; возможность обусловлена получением контракта; источник — ограниченный RSS-анонс |
| U_9250 / дизельная сделка | Ответ модели с перефразированной банковской цитатой отклонён. Локальный результат воздерживается от вывода о прямой связи; отдельный банковский фрагмент обозначен контекстом |
| U_9250 / портовый инцидент | Модель воздержалась от гипотез: связь с компанией не установлена |

| U_106783 / дизельная сделка | Цитата и IDs формально корректны. Связь топлива с электроэнергией и эффектом для предприятия слабая; требуется предметная проверка себестоимости. Это условная гипотеза, не подтверждённая возможность и не прогноз |

Предыдущий содержательный просмотр выявил шум по упоминанию страны, ссылки на
соседние статьи, художественный спецпроект с явным дисклеймером и потребительский
совет для садоводов. Эти случаи исключены до LLM и покрыты регрессией. Формальная
валидность цитат сама по себе не доказывает экономическую причинность.

Дальнейшая оценка для промышленного применения: экспертная разметка новых новостей,
отдельно precision отбора и ошибки механизмов, доля воздержаний, корректность
актуальности банковского контекста и доля подтверждённых применимых оснований.
Без такой разметки проценты бизнес-точности не публикуются.
