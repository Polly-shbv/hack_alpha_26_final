# Альфа Контекст 1.4.1

[Исходники на GitHub](https://github.com/Polly-shbv/hack_alpha_26_final) ·
[Автоматические проверки](https://github.com/Polly-shbv/hack_alpha_26_final/actions/workflows/verify.yml)

Локальное приложение персонализированной новостной аналитики в интерфейсе
интернет-банка: внешнее событие → контекст компании → потенциальное влияние →
аналитика банка → основания и ограничения. Три обезличенные компании U_9250,
U_1941, U_106783 сохранены и сверены с исходными CSV.

Сбор Lenta, РИА и ТАСС выполняется кнопкой. Основной анализ использует
**Google API, `gemma-4-26b-a4b-it`**: один запрос на пакет трёх компаний и до трёх
новостей на компанию, без автоматических повторов. Есть локальный режим без ключа,
проверка точных цитат, кэш, история, сравнение, сохранение, экспорт и обратная связь.
Прямые ссылки на оригиналы доступны в карточках и разборах. AI-помощник —
предусмотренное заданием окно «Скоро», без чата и обращений к моделям.

## Запуск

Требования: Python 3.12, Node.js 22.14+ и pnpm 11.25.0. Зависимости фиксируются
в `requirements.lock.txt` и `pnpm-lock.yaml`.

```sh
./scripts/bootstrap
./scripts/dev
```

Открыть [приложение](http://127.0.0.1:5173/select-company).
[API health](http://127.0.0.1:8000/api/v1/health), [OpenAPI](http://127.0.0.1:8000/docs).
В среде автора `.runtime-dir` указывает на проверенную локальную копию исходников
из-за особенностей чтения файлов macOS Documents. В архивы этот файл не включён.
Данные и история автора остаются в `data/local/alfa.sqlite3` исходного проекта.

Для просмотра без Node.js: распаковать `exports/alfa-context-demo.zip`, выполнить
`python3 start_demo.py` либо открыть «Запустить демо.command» / «Запустить демо.bat».
[Передача коллеге](docs/sharing.md).

## Docker

```sh
./scripts/docker-demo
```

Открыть [локальное приложение](http://127.0.0.1:8000/select-company).
Compose 2.24+; порт привязан к localhost. История хранится в именованном volume.
Обычный `docker compose down` сохраняет её. Проверка: `python3 scripts/check-container.py`.
Docker Desktop установлен: сборка и локальный контейнерный запуск проверены на Linux arm64.
Проверены API, сквозной сценарий и сохранение истории после перезапуска.

## Google API и конфигурация

Для режима без модели ключ не нужен. Для реальной аналитики скопировать
`.env.example` в `.env`, заполнить `ALFA_API_KEY` собственным ключом Google,
перезапустить сервер, в настройках выбрать реальный режим и разрешить передачу
обезличенного контекста. В рабочем экземпляре владельца это уже настроено.
Ключ хранится только на сервере. `.env` не передаётся в Git и архивы.

`.env.example` перечисляет provider/base/model/approved ID, нулевой тариф и лимиты
запросов. `ALFA_DB` меняет путь SQLite, `ALFA_ORIGIN` — разрешённый локальный origin.
`ALFA_COLLECTION_WORKER=0` применяется для изолированных тестов. Подробности:
[Google API](docs/google-api.md), [ручной пакет](docs/manual-batch.md).

## Архитектура

React + TypeScript + Vite, FastAPI/Python, SQLite/FTS5 и долговечная очередь.
Собственный оркестратор: профиль → поиск новостей → поиск банка → ранжирование →
интерпретация → проверка → атомарная публикация. При нехватке банковских оснований
поиск расширяется локально до единственного запроса к модели. Новые версии
публикаций не переписывают историю. Клиентские роли CEO/CFO/казначейство меняют
представление; viewer/analyst/admin управляют доступом.
[Подробная архитектура](docs/architecture.md), [контракты](docs/data-contracts.md).

## Данные и ограничения

Три профиля основаны на CSV, исходные CSV для запуска не требуются и в сдачу
не включены. Девять документов из папки кейса доступны как OCR-копии с provenance
и контрольными суммами; оригиналы сохранены у автора. OCR не вычитан полностью.
Учебные новости и девять synthetic-bank PDF помечены отдельно и остаются только
для воспроизводимого демо и тестов. [Реестр замены](docs/test-data-replacement.md).

ТАСС иногда возвращает 403: используется явно отмеченный RSS-анонс. Полнота
новостей зависит от источников. Для добавления новых банковских PDF есть механизм
официальных адресов alfabank.ru; конкретный адрес для внешнего отслеживания пока
не задан. Нет оснований обещать прогноз финансового результата или точность на
реальных клиентах. Недоступные признаки сохраняются как «Нет данных».

Демонстрационный вход предназначен для localhost. Банковский SSO, банковские
операции и публичный production-доступ не подключены. Приложение не оформляет продукты.

## Проверки и сдача

```sh
./scripts/test
./scripts/test-e2e
./scripts/build
python3 scripts/version.py
python3 scripts/package-demo.py
python3 scripts/package-source.py
```

Для браузерных тестов нужны запущенные backend/frontend с отдельной тестовой БД
и без ключа; Chromium: `pnpm exec playwright install chromium`.
Обычные pytest-тесты блокируют все сетевые соединения. CI выполняет backend/unit,
сборку, браузерные проверки, accessibility и отдельный Docker smoke. Пиксельная
macOS baseline проверена локально; на Linux CI этот единственный тест исключён
явно из-за отличий системного шрифта, функциональные и axe-проверки сохраняются.
